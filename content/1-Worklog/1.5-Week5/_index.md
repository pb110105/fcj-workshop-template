### Week 5 Objectives:

- Explore AWS services for monitoring, automation, and cloud resource management.

- Practice monitoring cloud infrastructure using Amazon CloudWatch Metrics, Logs, Alarms, and Dashboards.
- Understand AWS Access Key security best practices, performance optimization, resource efficiency, and AWS cost estimation.

### Week 5 Achievements:

**1. Exploring AWS Automation and Monitoring Services**

- Studied Amazon EventBridge Scheduler and its ability to schedule automated tasks on AWS.
- Learned about AWS Lambda and the serverless computing model, which allows applications to run without directly managing servers.
- Understood the role of Amazon CloudWatch in monitoring AWS resources, collecting operational data, and tracking system performance.
- Explored how EventBridge Scheduler, Lambda, and CloudWatch can work together to support automation and monitoring workflows.

**2. Configuration Management, Security, and Storage**

- Explored AWS Systems Manager Parameter Store for managing application configuration parameters.
- Learned about AWS Key Management Service (KMS) and its role in managing encryption keys and protecting sensitive data.
- Studied Amazon S3 and its fundamental concepts, including Buckets, Objects, and Storage Classes.
- Understood the importance of protecting sensitive information, managing access permissions, and securing data in AWS environments.

**3. Practicing Amazon CloudWatch Metrics and Logs**

- Became familiar with the Amazon CloudWatch management interface.
- Learned how CloudWatch Metrics are used to monitor AWS resource performance.
- Practiced viewing and analyzing monitoring data through CloudWatch Metrics.
- Explored CloudWatch Logs and its main components, including Log Groups and Log Streams.
- Practiced reviewing log data to support system monitoring and troubleshooting.
- Understood the differences between Metrics and Logs in cloud infrastructure monitoring.

**4. Practicing CloudWatch Alarms and Dashboards**

- Learned how to create CloudWatch Alarms based on monitoring metrics.
- Practiced configuring alarm thresholds to monitor AWS resource conditions.
- Explored CloudWatch Dashboards and their capabilities for visualizing monitoring data.
- Understood how dashboards can display multiple important metrics in a centralized interface.
- Reviewed and cleaned up AWS resources after completing the hands-on exercises to minimize unnecessary costs.

**5. AWS Access Key Security and Architecture Optimization**

- Understood the roles of Access Key ID and Secret Access Key in accessing AWS services through programming tools and the AWS CLI.
- Learned about the security risks associated with improperly stored AWS access keys.
- Reviewed AWS access key security best practices, including minimizing long-term credentials, controlling permissions, and deleting unused keys.
- Studied the Performance Efficiency pillar of the AWS Well-Architected Framework.
- Learned about the differences between performance optimization and efficient resource utilization.
- Explored the factors affecting AWS service costs and basic methods for estimating cloud infrastructure expenses.

**6. Knowledge and Experience Gained**

- Developed a better understanding of AWS monitoring and automation services.
- Gained foundational knowledge of CloudWatch Metrics, Logs, Alarms, and Dashboards.
- Learned how AWS services support configuration management, security, and cloud storage.
- Improved awareness of credential security and responsible AWS resource management.
- Understood the importance of system monitoring, performance optimization, and cost control when operating cloud infrastructure.
